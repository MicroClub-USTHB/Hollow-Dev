# Hollow Dev Challenges

This repository contains challenge statements for the Hollow Dev hackathon, organized by difficulty.

## Structure
- `1-Easy/` — beginner challenges
- `2-Medium/` — intermediate challenges
- `3-Hard/` — advanced challenges
- `MustRead.md` — rules and judging criteria

Participants can pick a challenge and build their solution in any tech stack while following the rules in `MustRead.md`.
